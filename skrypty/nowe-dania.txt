# Lista dań do wygenerowania — jedna linia na danie:
#
#     Nazwa dania|rodzaj
#
# Rodzaj musi być jednym z: sniadanie, obiad, kolacja, zupa, przekaska,
# deser, dodatek, surowka. Literówka w rodzaju = skrypt się zatrzyma i powie,
# w której linii (danie z lewym rodzajem zniknęłoby z filtrów w apce).
#
# Puste linie i linie zaczynające się od # są pomijane.
# Dania, które już są w bazie, zostaną pominięte przy generowaniu.
#
# ── PACZKA 5: kuchnia chińska, 37 dań ──
#
# Filip prosił o „makaron chiński z kurczakiem jak padthai". Pad thai jest
# tajski, nie chiński — chińskim odpowiednikiem smażonego makaronu jest
# CHOW MEIN (makaron smażony na chrupko) i LO MEIN (miękki, mieszany z sosem).
# Oba są tu na początku listy. Gdyby Filip chciał jednak samego pad thaia,
# to osobna paczka tajska.
#
# W bazie chińszczyzny prawie nie było: „Kurczak po chińsku", „Kurczak
# w sosie słodko-kwaśnym", „Spring rolls (sajgonki)" i dwa smażone ryże.
# Ta lista ich nie powtarza — sprawdzone tą samą logiką co `npm run duble`,
# zestawiając ją z wszystkimi 539 daniami bazy.
#
# Nazwy trzymają styl bazy: bez myślników, chińska nazwa tam, gdzie jest
# tożsamością dania (chow mein, mapo tofu, gong bao, dan dan), polski opis
# tam, gdzie sama nazwa nic nie mówi.
