# Lista dań do wygenerowania — jedna linia na danie:
#
#     Nazwa dania|rodzaj
#
# Rodzaj musi być jednym z: sniadanie, obiad, kolacja, zupa, przekaska,
# deser, dodatek, surowka. Literówka w rodzaju = skrypt się zatrzyma i powie,
# w której linii (danie z lewym rodzajem zniknęłoby z filtrów w apce).
#
# Puste linie i linie zaczynające się od # są pomijane.
# Dania, które już są w bazie, zostaną pominięte przy generowaniu.
#
# ── PACZKA 3: kuchnia włoska, 100 dań (stan bazy przed nią: 439) ──
# W bazie było już 48 dań z włoskim rodowodem (carbonara, bolognese, lasagne,
# risotto, gnocchi, tiramisu, panna cotta, minestrone, caprese, bruschetty) —
# ta lista ich nie powtarza. Sprawdzone `npm run duble` przeciwko całej bazie.
#
# Śniadań tylko 4, bo włoskie śniadanie to realnie cornetto i kawa — nie ma
# sensu naciągać kategorii na siłę.
