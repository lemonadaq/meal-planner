# Lista dań do wygenerowania — jedna linia na danie:
#
#     Nazwa dania|rodzaj
#
# Rodzaj musi być jednym z: sniadanie, obiad, kolacja, zupa, przekaska,
# deser, dodatek, surowka. Literówka w rodzaju = skrypt się zatrzyma i powie,
# w której linii (danie z lewym rodzajem zniknęłoby z filtrów w apce).
#
# Puste linie i linie zaczynające się od # są pomijane.
# Dania, które już są w bazie, zostaną pominięte przy generowaniu.
#
# ── PACZKA 4: kuchnia koreańska, 54 dania (stan bazy przed nią: 539) ──
#
# Powód: Filip kupił pastę gochujang. Lista dzieli się na dwie części, bo
# gochujang z definicji piecze — słodko-fermentowana, ale ostra. Dania bez
# ostrości to osobna grupa i NIE ma w nich ani gochujangu, ani gochugaru,
# ani kimchi.
#
# W bazie było tylko jedno danie koreańskie („Bibimbap z wołowiną"), więc
# nic się tu nie powtarza. Sprawdzone `npm run duble` przeciwko całej bazie.
#
# Nazwy trzymają styl reszty bazy: bez myślników, koreańska nazwa tam, gdzie
# jest tożsamością dania (tteokbokki, japchae, kimbap), polski opis tam, gdzie
# sama nazwa nic nie mówi (gyeran jjim → „koreański omlet parowany").
